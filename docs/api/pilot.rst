Pilot Data (pyavs.pilot)
=============================

.. note::

   This module loads and enriches **pilot-phase** eye-tracking data -- a distinct,
   earlier-stage dataset from the main AVS experiment (as01-as05) documented elsewhere in
   this site. Ported from the standalone ``pilot-data-manager/`` package.
