Citation
============

Dataset Paper
-----------------

If you use the AVS dataset or pyAVS in your research, please cite the dataset paper:

    Sulewski, P., Amme, C., König, P., Hebart, M. N., & Kietzmann, T. C. *Active Visual
    Semantics: A large-scale MEG and eye-tracking dataset for understanding visual
    intelligence in action.* Manuscript in preparation.

.. code-block:: bibtex

   @article{sulewski_avs_inprep,
     author  = {Sulewski, Philip and Amme, Carmen and K{\"o}nig, Peter and
                Hebart, Martin N. and Kietzmann, Tim C.},
     title   = {Active Visual Semantics: A large-scale {MEG} and eye-tracking
                dataset for understanding visual intelligence in action},
     note    = {Manuscript in preparation},
   }

Software
------------

Analysis code and the pyAVS package are developed at
`github.com/KietzmannLab/pyavs <https://github.com/KietzmannLab/pyavs>`_. If you use pyAVS
itself, please also cite/link the repository and, where relevant, the specific release or
commit you used.
